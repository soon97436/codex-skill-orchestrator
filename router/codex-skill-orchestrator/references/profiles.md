# Profile behavior

The installer writes one resolved profile to `active-profile.json`. That generated file is the only profile the router needs during normal use.

- **Universal:** balanced everyday routing.
- **Economy / Save Usage:** few routes, concise output, explicit invocation preferred.
- **Deep Reasoning:** broader analysis and independent verification.
- **Small Project:** implementation, testing, and review with little orchestration overhead.
- **Large Project:** architecture mapping, staged work, integration testing, and review.
- **Research:** primary-source discovery, synthesis, and citation verification.
- **Security:** threat modeling, dependency analysis, remediation, and verification.
- **Custom:** Universal plus a user-maintained routing slot.

`capability_hints` are generic labels. Select a hinted capability only when the current runtime exposes a suitable skill; otherwise continue with built-in tools or explain the missing capability.
